## Part B — Visual / technical QC

### Picture
- [ ] Correct resolution, ratio and frame rate for the platform (DOC-09)
- [ ] No black bars, unintended letterboxing or pillarboxing
- [ ] No flash frames, gaps, jump frames or duplicate frames
- [ ] Horizons and verticals level
- [ ] Focus sharp on garment and faces in hero shots
- [ ] No digital zoom beyond DOC-06 §7 limits; no visible softness from scaling
- [ ] Recomposition preserves full silhouettes (feet and cap) where intended
- [ ] No unwanted objects, branding, crew or equipment in frame

### Colour
- [ ] Skin tones accurate and rich, not grey, ashy or orange
- [ ] Garment colour matches reference still under daylight
- [ ] Shadows deep but detailed; highlights not clipped on white/ivory fabric
- [ ] Grade consistent across shots in each scene
- [ ] Viewed on a calibrated monitor **and** a phone

### Typography and captions
- [ ] Approved fonts only (max two families)
- [ ] Captions match narration word for word
- [ ] Yoruba tone marks correct; proofread by fluent reviewer
- [ ] Inside platform safe zones; consistent placement
- [ ] No spelling errors (product names, place names, people's names)
- [ ] Contrast at least 4.5:1

### Logo
- [ ] Official file only (never recreated)
- [ ] Proportions locked; correct colour version
- [ ] Clear space and size within DOC-03 limits
- [ ] Appears only at approved positions; no effects

## Part C — Audio QC

- [ ] Integrated loudness −14 LUFS (±1) for social/YouTube; true peak ≤ −1 dBTP
- [ ] Narration clear on phone speakers
- [ ] Music does not compete with narration
- [ ] No clicks, pops, hum, clipping or abrupt cuts in ambience
- [ ] No whooshes/risers on transitions
- [ ] Sonic signature or Still Beat at end card
- [ ] Audio in sync throughout
- [ ] Music licence covers this platform and use (organic / paid)

---

## Part D — Authenticity and rights QC

- [ ] All garments shown are real ANKOO products as sold (or clearly labelled concept/prototype)
- [ ] No invented founder experiences, testimonials, customers, facilities, history or achievements
- [ ] AI use logged in the AI register; no AI material presented as genuine documentation (DOC-12)
- [ ] Founder cloned voice used only for approved script with consent on file
- [ ] Release forms filed for every identifiable person
- [ ] Location permissions filed
- [ ] Music licences filed
- [ ] Cultural content reviewed by knowledgeable reviewer

---

## Part E — Publishing readiness

- [ ] File named per convention (DOC-06 §4.2)
- [ ] Caption file (.srt) exported where applicable
- [ ] Post copy written in ANKOO voice; proofread
- [ ] Cover/thumbnail chosen (a held, composed frame)
- [ ] Alt text written for stills
- [ ] Destination folders: copy to `09_SOCIAL_MEDIA_EXPORTS/<PLATFORM>/` after approval
- [ ] **Founder approval recorded** (DOC-08 §7) — required before any publishing
